# Ad-Scout: поиск вечнозелёных (evergreen) товаров через Meta Ad Library

Проект сканирует активную видео-рекламу в Meta Ad Library (через SearchAPI.io) и отбирает вечнозелёные физические товары для e-commerce.

## Архитектура

- `scan.js` — сканер. Вызывает SearchAPI.io Meta Ad Library API по списку категорий, сохраняет сырые ответы в `data/raw/<slug>.json` и агрегированный список кандидатов в `data/candidates.json`.
- `data/` — результаты сканов (raw JSON не коммитим, только отчёты).
- `reports/` — итоговые аналитические отчёты (markdown).

## API

- Endpoint: `GET https://www.searchapi.io/api/v1/search`
- Параметры: `engine=meta_ad_library`, `ad_category=all`, `q={keyword}`, `country=US`, `active_status=active`, `media_type=video`, `api_key={key}`
- Ключ берётся из переменной окружения `SEARCHAPI_KEY` (лежит в `.env`, НЕ коммитить).

## Категории для скана

pet products, kitchen gadgets, baby safety, posture corrector, skincare tools,
travel accessories, desk accessories, home gym, gardening tools,
personalized gifts, everyday carry.

Запуск: `node scan.js "pet products" "kitchen gadgets" ...` (без аргументов — все категории).

## Пайплайн отбора

### Шаг 1 — Скан
Собрать активные видео-объявления по категориям. Сигнал качества: реклама, которая крутится долго (смотрим `start_date` — чем старше активное объявление, тем сильнее сигнал, что оффер прибыльный).

### Шаг 2 — 5 гейтов (жёсткий фильтр, все обязательны)
1. **Margin ≥3x** — retail-цена минимум в 3 раза выше оценочной закупочной (sourcing по опыту Alibaba/1688).
2. **Halal compliance** — нет алкоголя, свинины, gambling, обмана/скам-механик, харам-контента.
3. **IP/Legal risk** — нет брендовых подделок, лицензионных персонажей, патентных мин.
4. **Logistics** — вес до 2 кг, не хрупкое, не батарейки-проблемные габариты.
5. **Evergreen** — не сезонный, решает постоянную (перманентную) проблему покупателя.

### Шаг 3 — Скоринг 0–100 (для прошедших гейты)
| Критерий | Вес | Что оцениваем |
|---|---|---|
| Longevity | 25% | Как долго крутится реклама (start_date активных объявлений, число вариаций) |
| Marketing Angle | 25% | Можно ли построить бренд/историю, эмоциональный крючок |
| Margin | 20% | Реальная маржа с учётом доставки и CPA |
| Competition | 15% | Насыщенность ниши (меньше конкурентов = выше балл) |
| Wow Factor | 15% | «Стоп-скролл» эффект, демонстрируемость в видео |

### Шаг 4 — Глубокий анализ топ-10
Для каждого: маркетинговый угол, идея UGC-видео, целевая аудитория,
юнит-экономика (COGS / retail / CPA / маржа), стратегия дифференциации.

## Правила

- Тестовый прогон — 3 категории, полный — все 11.
- Между API-запросами пауза ≥1 сек (rate limit).
- Отчёты писать в `reports/scan-YYYY-MM-DD.md` на русском.
- Дедупликация кандидатов по page_name + названию товара.
