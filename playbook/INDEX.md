## 🎯 1. Рабочие углы (angles) — главный вход в креатив
- **Разработка углов** — `part1 §3.4`. Угол = «аудитория × боль/желание × формат». Товар не выгорает —
  выгорает угол. Матрица: строки = аудитории (мамы / офисные / геймеры / пожилые / подарок),
  столбцы = драйверы (боль / экономия денег / экономия времени / статус / страх / забота о близком).
  Каждая осмысленная клетка = сценарий. Запуск 3–5 углов параллельно.
- **Связка сегмент → угол → крео** (конвейер) — `part2 §6.3`.
- **Оси сегментации, порождающие разные крео** — `part2 §6.2`.
- **Смещение оси конкуренции (товар → оффер/угол)** — `part1 §5.1`.
- **Механизм как дифференциатор** — `part1 §5.2`; **доверие** — `part1 §5.3`; **формула позиционирования** — `part1 §5.5`.
- **Фрейминг: одна правда — разная упаковка** — `part3 §13.2`.

## ✍️ 3. Копи-структуры (PAS / AIDA / BAB / FAB)
Все — `part1 §3.3`.
- **AIDA** — Attention → Interest → Desire → Action. Каркас лендинга сверху вниз и сценария 30–60 сек.
- **PAS** — Problem → Agitate → Solve. Лучший каркас для холодного трафика (ур. 2 осознанности);
  агитация = 1–2 бытовых последствия, не запугивание. Опора на loss aversion — [эмпирика].
- **BAB** — Before → After → Bridge. Продаёт трансформацию (dream outcome); lifestyle-товары.
- **FAB** — Features → Advantages → Benefits. Блок характеристик: каждую строку дописывать до выгоды.
- Смежное: **механика хука (первые 2–3 сек)** — `part1 §3.1`; **форматы видео-крео** — `part1 §3.2`.

## ☪️ 4. Халяль-фильтр / этические границы (обязательный гейт)
Раздел 15 целиком (`part3`). Ключевое:
- **Сводный прогон-фильтр 15.5** — `part3 §15.5`. Пять блоков, применяются к ГОТОВОМУ крео+офферу:
  - **А — Правда:** заявления обоснованы · демо честное · Before/After реальные · ограничения раскрыты · отзывы настоящие · роль бренда честная.
  - **Б — Деньги:** нет риба-механик · зачёркнутые цены реальные · экономика учитывает возвраты.
  - **В — Срочность:** таймеры/лимиты привязаны к реальным событиям · ничего не перезапускается · дефицит = факт.
  - **Г — Достоинство:** без страха/стыда/эксплуатации уязвимости · скромность визуала под рынок · товар делает обещанное.
  - **Д — Комплаенс:** политика платформы (health-клеймы, B/A) · IP/товарные знаки чисты · права на контент есть.
  - *Правило:* один провал любого пункта = доработка ДО запуска.
- Детали: **правдивость заявлений (гарар/гишш)** — `§15.1`; **риба/оплата** — `§15.2`;
  **честная срочность и дефицит** — `§15.3`; **достоинство аудитории** — `§15.4`.
- Визуальная халяль-адаптация под рынок — `part1 §4.5`.

> Этот фильтр = основа честность/халяль-проверки в `/templates/HOW-TO.md`. В craft-движке ни один
> промпт не уходит в модель без прогона блоков А–Д.
